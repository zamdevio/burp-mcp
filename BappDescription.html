burp-mcp integrates Burp Suite with AI clients using the Model Context Protocol (MCP). It is a GPL-3.0 derivative of PortSwigger’s official MCP Server extension, maintained at github.com/zamdevio/burp-mcp. It does not replace the official BApp.

The extension runs an MCP server inside Burp so assistants can send HTTP, read proxy history, operate Repeater tabs, and use other Burp tools — subject to the approval gates in the MCP tab.

Note: Any data sent to external tools via this extension is subject to their data processing policies. Use only against targets you are authorized to test.

Features

  • Send HTTP/1.1 and HTTP/2 requests from AI clients with optional approval and auto-approved targets
  • Access and filter proxy history (HTTP and WebSocket) with regex support
  • List, read, write, select, and rename individual Repeater tabs (live Burp UI)
  • Create Repeater tabs and send requests to Intruder
  • Generate and poll Burp Collaborator payloads (Professional only)
  • List scanner issues (Professional only)
  • Export and merge project and user configuration via JSON (opt-in)
  • Control proxy intercept, task execution engine, and the focused message editor
  • Encoding utilities (URL, Base64) and random string generation
  • Claude Desktop installer plus packaged stdio proxy for clients that cannot speak SSE
  • Organizer item listing

Usage

  1. Navigate to the MCP tab and enable the MCP server (default http://127.0.0.1:9876).
  2. Configure approval settings and auto-approved HTTP targets as needed.
  3. Connect an SSE client, use Install to Claude Desktop, or run the packaged stdio proxy.
  4. Call MCP tools from the client. See the project README for the current tool list.
